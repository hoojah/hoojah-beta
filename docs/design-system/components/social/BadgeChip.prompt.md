Achievement chips, only ever shown on the indigo profile header.

```jsx
<BadgeChip {...BADGES.first_debate} title={BADGES.first_debate.description} />
```

There are exactly four badges: First Hoojah (award), First Argument (message-circle), First Follower (users), First Debate (swords). The chip is `white/20` on the blue — it has no light-background variant.
