The share-2 glyph and its dropdown, pinned to the right of a hoojah's byline.

```jsx
<ShareMenu onShare={(t) => track(t)} />
```

The trigger glyph is 16px `--text-faint`. "Share…" is the native OS sheet and only appears where the Web Share API exists. Share copy pattern: `"<body> (by @handle)" Do you AGREE? NEUTRAL? DISAGREE?` — the only place Hoojah shouts in caps.
