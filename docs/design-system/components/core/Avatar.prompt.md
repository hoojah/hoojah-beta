A round user photo with an initials-on-indigo fallback.

```jsx
<Avatar name="Maya Zaharudin" size={44} />
<Avatar src={user.photo} name={user.full_name} size={96} />
```

Sizes used in the product: 96 (profile header), 44 (hujah card header, composer), 40 (follower row), 36 (navbar), 32 (compact card, debate turn, parent stub).
